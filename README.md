Fullstack Complaint Portal

A full-stack web application for registering, tracking, and managing complaints efficiently. This platform allows users to submit complaints, track their status, and enables admins to manage and resolve them seamlessly.

Features

User Registration & Authentication – Secure login and signup system.

Complaint Submission – Users can lodge complaints with detailed descriptions.

Complaint Tracking – Track the status of complaints in real-time.

Admin Panel – Admins can view, update, and resolve complaints.

Responsive Design – Works across desktop and mobile devices.

Installation

Clone the repository:

git clone https://github.com/Harini410/Fullstack-complaint-portal.git
cd Fullstack-complaint-portal


Install backend dependencies:

cd backend
npm install


Install frontend dependencies (if separate frontend folder):

cd ../frontend
npm install


Setup environment variables:

# Example
PORT=5000
DB_URI=your_database_uri
JWT_SECRET=your_jwt_secret


Run the application:

# Backend
npm start

# Frontend
npm start

Usage

Register as a new user or log in.

Submit a new complaint using the complaint form.

Track the status of your complaints.

Admins can log in to manage and resolve complaints.
